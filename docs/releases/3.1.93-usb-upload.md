# Inhouse Photos 3.1.93

- Prefer a verified USB network route, otherwise local Wi-Fi or public HTTPS.
- Switch new transfers without interrupting uploads already using a valid route.
- Revalidate routes while backing up and preserve normal mobile-data restrictions.
- Detect stalled transfers by inactivity rather than total file duration.
- Use the same bounded scheduler for manual uploads: up to 16 photos and one
  exclusive video, with bounded pending cloud compression.
- Show cable / local network / Internet and a stable measured MiB/s readout.
- Explain a negotiated 100 Mbps PC link instead of suggesting unlimited Wi-Fi
  bandwidth. Keep server/account identity and original certificate validation.

USB requires a data cable plus OS USB network sharing, and Windows manager
1.2.14. It does not use charging/MTP mode, ADB, a VPN or an unauthenticated HTTP
address. The first new USB address must be discovered while the public server
is reachable; remembered addresses still require successful authenticated-host
TLS and a server health probe. Keep the mobile app open for direct transfers.

Existing accounts and already backed-up photos are unchanged. Actual maximum
speed depends on the physical PC network, phone, USB cable, storage and drivers.
