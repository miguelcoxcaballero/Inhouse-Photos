# Inhouse Photos Server 1.2.2 (Windows)

The manager, installer, and new-library wizard now share a calmer, lighter
interface. Clear headings and spacing lead each screen; color marks the main
action and important status instead of decorating every panel. The overview
puts server health, free space, backup status, and mobile connection first.

Existing-library adoption is still copy-and-verify only. This release does not
move, delete, or re-encode photos, replace the running server, or change user
accounts. Closing the manager does not stop the server. The optional Windows
sign-in startup setting remains off until enabled by the user.

Windows 10/11 and .NET Framework 4.8 are required. The binaries are not
Authenticode-signed; SHA-256 checksums are published separately.
