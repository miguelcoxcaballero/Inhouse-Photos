# Inhouse Photos 3.1.96 para Windows

La app y el programa de Windows comparten la versión 3.1.96. La pantalla Gestión del servidor ofrece una única acción para actualizar Inhouse Photos y muestra su progreso.

La actualización guarda su intención antes de reiniciar el programa y continúa después del reinicio. Conserva la biblioteca, la base de datos y el trabajo pendiente. Si una actualización antigua quedó interrumpida y requiere reparación local, la app ofrece las instrucciones y el instalador publicado.

El instalador conserva el mecanismo de actualización existente y se verifica con instalaciones reales desde 1.2.16 y 1.2.17 en un entorno Windows aislado. La publicación comprueba los ejecutables x64, la versión, el contenido del instalador, los recursos integrados, la intención de actualización y las transacciones del actualizador.

El ejecutable no está firmado con Authenticode; se publica su SHA-256. No requiere desactivar SmartScreen ni el antivirus.
