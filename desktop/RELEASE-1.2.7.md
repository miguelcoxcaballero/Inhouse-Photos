# Inhouse Photos Server 1.2.7 (Windows)

Adds automatic discovery of the computer's LAN address for faster uploads from
the mobile app when both devices are on the same home network. The mobile app
continues to use the public HTTPS hostname and its normal certificate, and
falls back to Internet access automatically when the local route is unavailable.

This release also corrects the Windows manager's internal version identifier
so future updates are recognized accurately. Installing the manager does not
move, delete or recompress photos, change accounts, or stop the photo server.
