# Inhouse Photos 3.1.79 — smoother gallery

- Metadata refreshes avoid rebuilding unchanged rows in the refreshed window,
  while other visible rows still revalidate their data.
- Preview composition stays deferred until the grid transition finishes.
- Cached previews are drawn in batches instead of one draw call per photo.
- Correct sprite positioning keeps previews visible throughout the transition.
- Completed preview sheets are shared without repeatedly indexing partial sheets.
- Grid transitions continue to reuse full-resolution cached previews.

Install over the existing app. No migration or server change is required.
