# Inhouse Photos Server 1.2.6 (Windows)

The manager publishes the computer's current private LAN address for faster
phone backups on the same home network. It refreshes that address while the
manager is running and the server is healthy. A new managed server includes
the discovery route automatically; the current migrated server has also been
configured without moving its library or database.

The mobile app still connects to its normal HTTPS hostname and validates its
certificate. If local access is unavailable, backup uses the public route.

Installing this manager replaces only the Windows program. It does not delete,
move or recompress existing photos and does not change login credentials.
