Tu biblioteca no pasa por esta web.

Este portal solo ofrece información y enlaces de descarga. No pide cuenta, contraseña ni acceso a tus fotos.

Al descargar

Los archivos se alojan en GitHub Releases. GitHub puede registrar datos técnicos de acceso según sus propias políticas.

Al usar Inhouse Photos

Tu servidor, no esta página, recibe las fotos y gestiona las cuentas. Quien administra la instalación controla su dirección y su configuración. El acceso remoto requiere que el servidor esté encendido y disponible por HTTPS.

Lo que no hacemos

Inhouse Photos no añade analítica, píxeles publicitarios ni cookies de seguimiento. El alojamiento del sitio puede generar registros técnicos de acceso para funcionar.

Si usas el servidor de otra persona

Para saber cómo trata los datos una instalación concreta, pregunta a quien la administra.
