# Inhouse Photos 3.1.78 — sharp grid reflow

- Photos rearrange using their current on-screen positions when zooming,
  including when another pinch interrupts the transition.
- Real previews are shared across grid sizes. Full physical preview resolution
  replaces the previous 75% limit at dense zoom levels.
- Bounded, leased image sheets keep visible pixels alive through cache eviction;
  a late disk restore cannot replace a newly sharpened panel.
- Same-count uploads and edits refresh photo data separately from grid geometry.
- Timestamp ties no longer cause local or cloud photos to be skipped during
  forward pagination.
- Unreadable local files no longer block the thumbnail-generation queue.
- Added focused mobile regression CI without upstream publishing credentials.

Includes an Android native contact-sheet benchmark prototype. It is not enabled
in the gallery pending physical-device measurements; see `../sharp-grid-reflow.md`.

Install this signed APK over the existing app. No server changes, photo migration,
or uninstall are required. Previously unseen cloud previews still need an initial
network download; no universal frame-rate guarantee is implied.
