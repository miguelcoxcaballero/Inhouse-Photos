# Inhouse Photos 3.1.80

- Grid sizes respond during the pinch gesture, with coalesced changes and a
  shorter reflow. Starting another gesture no longer snaps an ongoing transition
  to its final position. High-resolution previews remain available.
- Cancelling a backup releases queued upload workers waiting for server
  compression capacity. Workers check cancellation again before sending bytes.
- Includes an early Windows server manager for existing installations: health,
  disk space, mobile endpoint setup and non-mirroring backups.

Windows 0.1 does not yet provision a fresh server or configure RAID internally.
It is not Authenticode-signed. Credentials are never bundled in downloads.
Android installs over the existing app with the permanent signing key.
