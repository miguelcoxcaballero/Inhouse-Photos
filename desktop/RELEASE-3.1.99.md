# Inhouse Photos 3.1.99 para Windows

Nuevo diseño del gestor de Windows y de la web de descargas.

El gestor tiene una navegación más clara, pantallas que empiezan por el estado
de la biblioteca y una sola acción principal en cada una. Durante una copia de
seguridad se muestra su progreso en la propia pantalla de Copias.

La web de descargas muestra la pantalla real de copia de seguridad de la app y
deja las descargas de Android y Windows en una sola tabla.

No cambia el funcionamiento: el motor interno sigue siendo el 3.1.97 ya
verificado. Las fotos, cuentas, álbumes, discos y trabajos pendientes se
conservan. El instalador completo es `Inhouse-Photos-Server-Full-Setup.exe`;
ambos instaladores tienen su SHA-256 en `SHA256SUMS.txt`.
