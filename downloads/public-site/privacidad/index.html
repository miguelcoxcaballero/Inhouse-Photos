PRIVACIDAD

Tu biblioteca no pasa por esta web.

Este portal ofrece información y enlaces de descarga. No pide una cuenta, contraseña ni acceso a tus fotografías. Tampoco contiene un formulario de vinculación que envíe datos a terceros.

Al descargar las aplicaciones

Los archivos se alojan en GitHub Releases. GitHub puede registrar datos técnicos de acceso conforme a sus propias políticas. Consulta el enlace de descarga antes de instalar nada.

Al usar Inhouse Photos

Tu servidor, no esta página, recibe las fotos y gestiona la cuenta. La dirección y la configuración del servidor las controla quien administra esa instalación. El acceso remoto requiere que el servidor esté encendido y disponible por HTTPS.

Qué no hacemos aquí

Este portal no usa analítica propia, píxeles publicitarios ni cookies de seguimiento añadidas por Inhouse Photos. El alojamiento del sitio puede generar registros técnicos de acceso para su funcionamiento.

Última actualización: septiembre de 2026. Para conocer cómo trata los datos una instalación concreta, consulta a quien la administra.
